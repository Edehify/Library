# Library

## Description

Library is a simple library application that allows users to add books, display their books, update their reading status, and delete books from their library.

For more information about this project and my learning journey, please visit:  
[The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-library)

## Features

* Add a book
* Display books
* Delete a book
* Update the book's reading status

## What I Learned

- How to use JavaScript constructors to create objects.
- How the `this` keyword works inside constructors and methods.
- How prototypes allow objects to share methods.
- How to create and manipulate arrays of objects.
- How to use `crypto.randomUUID()` to generate unique IDs.
- How to manipulate the DOM with JavaScript.
- How to create and update HTML elements dynamically.
- How to use event listeners to handle user interactions.
- How to work with HTML forms and form submission.
- How to use the `<dialog>` element to create a modal form.
- How to use methods such as `forEach()`, `findIndex()`, and `splice()`.
- How to update the DOM when data changes.
- How to use CSS Grid and Flexbox to create a responsive layout.
